# 🎢 ReelerCoaster

> **Умная автоматическая нарезка горизонтальных видео в вертикальные Reels, Shorts и TikTok (9:16) с AI-хайлайтами, динамическими караоке-субтитрами и авто-кадрированием.**

---

## ⚡ Особенности и фичи

1. **Два режима нарезки:**
   - ✂️ **Серии / Полная нарезка (Part 1, Part 2...):** Разрезает всё видео целиком на последовательные серии (по 1 мин, 1.5 мин или 2 мин). AI автоматически находит **выгодные паузы в речи и концы предложений**, чтобы завершать части логично и не обрезать слова на полуслове. Каждому клипу добавляется стильный бейдж `⚡ ЧАСТЬ 1 ⚡`.
   - 🔥 **Органические Хайлайты (Event-Arc Detection):** Алгоритм не просто берёт фиксированные отрезки, а находит **эпицентр эмоций/геймплея** (крик, смех, хайп), отматывает назад к началу фразы/действия и отслеживает момент до естественного затухания и паузы в речи. Длительность каждого хайлайта гибкая и живая!

2. **2 режима кадрирования (9:16):**
   - 🎙️ **IRL / Разговорный:** Автоматический трекинг лица и головы (Face Tracking через нейросеть OpenCV YuNet) со сглаживанием траектории камеры (без рывков и дерганий).
   - 🎮 **Гейминг:**
     - **🎯 Свободный интерактивный выбор вебки:** Интерактивная рамка на превью кадра — перетаскивайте мышкой и растягивайте за угол прямо в браузере в любое место стрима (или выбирайте быстрые пресеты).
     - **Сплит-скрин с вебкой:** Вебка стримера масштабируется в верхнюю треть, а центрированный геймплей — в нижние две трети с аккуратным неоновым разделителем.
     - **Чистый геймплей:** Центрированный кроп на центр экшена.
     - **Fit + Blur:** Полный 16:9 геймплей по центру с динамически размытым фоном сверху и снизу (чтобы не терять HUD и карту).

3. **Динамические субтитры (Whisper AI):**
   - Распознавание речи с точностью до отдельных слов (`word_timestamps`).
   - Стилизация под MrBeast / Alex Hormozi (караоке-эффект: активное слово подсвечивается ярким цветом и увеличивается в размере).
   - Безопасная зона отступов: субтитры не перекрываются кнопками TikTok / Reels.

4. **Аппаратное ускорение и потоковая нарезка (Audio-First):**
   - **Zero-Disk Streaming (Полный файл больше НЕ качается на диск):** При обработке ссылок программа скачивает **только звук (~30–60 МБ)** для поиска моментов и субтитров, а затем вытягивает через HTTP-диапазоны **только точечные 30–60 секундные куски**. Исходный 20-гигабайтный файл ни на одну секунду не сохраняется на диске!
   - **Турбо-закачка с YouTube/Twitch:** встроенный обход троттлинга (`player_client=android`), многопоточная закачка (до 16 соединений через `aria2c`), без потери качества (0% потерь).
   - **Защита от повторных закачек (Дедупликация):** мгновенное распознавание уже обработанных ссылок.
   - **Умная экономия диска (Авто-очистка):** после нарезки все временные файлы мгновенно удаляются — на диске остаются только готовые Reels!

5. **Удобный Web UI:**
   - Темная Cyberpunk / Glassmorphism тема.
   - Прием ссылок (YouTube, Twitch, TikTok и др.) через `yt-dlp` или прямая загрузка локальных видео.
   - Встроенный видеоплеер 9:16 для предварительного просмотра и скачивания готовых клипов в 1 клик.

## 🚀 Быстрый запуск

### Вариант 1 (Windows - 1 клик):
Просто запустите файл:
```bat
run.bat
```

### Вариант 2 (Через терминал):
```bash
# Активация окружения (если используется .venv)
.\.venv\Scripts\activate

# Запуск студии
python main.py
```
После запуска откройте в браузере: **`http://localhost:8000`**

## 🛠 Структура проекта

```
ReelerCoaster/
├── core/
│   ├── downloader.py          # Загрузка по ссылкам (yt-dlp) и сохранение файлов
│   ├── ffmpeg_utils.py        # FFmpeg обёртка с поддержкой NVENC и фильтров
│   ├── highlight_detector.py  # Анализ аудио-энергии и поиск лучших моментов
│   ├── face_tracker.py        # Трекинг головы для IRL-режима
│   ├── framing.py             # Генератор кадрирования (IRL & Gaming Split-Screen)
│   ├── transcriber.py         # Whisper транскрибация по словам
│   ├── subtitle_burner.py     # Генерация ASS караоке-субтитров
│   └── pipeline.py            # Полный конвейер обработки
├── web/
│   ├── templates/index.html   # Современный веб-интерфейс
│   └── static/                # Стили и клиентские скрипты
├── storage/                   # Папка для исходников и готовых Reels
├── config.py                  # Настройки и пути
├── main.py                    # FastAPI сервер
└── run.bat                    # Быстрый запуск
```
